# 见微 · 博主观点复盘簿

这是旧版静态网站，仅保留用于导出浏览器记录。新版请在项目根目录使用 `docker compose up --build -d --wait` 启动。

如果需要访问旧版，在项目根目录运行 `node server.cjs`，随后访问 http://127.0.0.1:4173/legacy/index.html 。关闭启动它的终端即可停止服务。固定使用这个地址，避免切换域名或端口导致看不到原有浏览器数据。

也可直接打开 `index.html`。不同浏览器对本地文件存储的支持不同，推荐使用上面的本地服务，并固定在同一浏览器打开。

## 功能

- 总览：观点数量、复盘队列、评分轨迹和博主观察榜。
- 博主档案：平台、主题、备注，支持新增、修改和删除空档案。
- 观点台账：记录原话、发表日期、操作、主题、方向、周期、原文链接、成立与失效条件；搜索和筛选。
- 复盘工作台：按回看日期排序，手动评估结果、时点、风险和可验证性。支持修改或撤销复盘。
- 可选起止价、同区间基准涨跌幅；单独显示标的价格区间回报，不将其视为实际交易收益。
- JSON 导出、校验与恢复；覆盖前需确认，并保留一份导入前的原始副本于浏览器 `jianwei.local.previous` 键。
- 手写笔记原图保存在 `assets/handwritten-notes.jpg`，供人工核对，不进行 OCR 或自动归属。
- 手机和桌面布局均可使用。

首次打开是明确标注的虚构演示。点击「开始我的记录」清除演示，建立个人空间。未核对原文和日期的记录不进入评分；编辑已有复盘的原始观点会撤销旧复盘，界面会提前说明。

## 保存范围

数据保存在当前浏览器的 localStorage，并不会写回项目文件夹。**请定期导出 JSON 备份**；清除网站数据、换浏览器、换网址或换电脑都可能导致原有数据不可见。恢复备份会校验格式并覆盖当前空间。笔记原图随整个网站文件夹保存，不包含在 JSON 中。

本地网页不自动抓取博主内容、不接入行情，也不自动判定荐股成败。原文与评分由使用者核对填写。四维权重为 40/25/20/15，每项 0–5 分，满分 100。博主均分按有效复盘记录等权计算；样本数始终同时显示。

## 开发

原生 HTML / CSS / JavaScript；静态服务器只绑定 `127.0.0.1:4173`。直接运行 `node server.cjs` 即可启动。没有构建步骤，不向外部服务发送请求。

运行 `node --test self-test.cjs` 检查评分、存储失败保护、备份校验、筛选和表单保存逻辑。
